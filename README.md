# Meeraas-e-Kashmir 🍎

High-density apple orchards in the Kashmir valley, planted and managed for private clients.

**Website:** https://meeraas-e-kashmir.github.io

The site explains how a modern high-density orchard works, shows the price evidence behind our assumptions, and includes a 20-year returns calculator built from our orchard cashflow model. Enter a budget or a number of kanals to see Year-1 investment, payback year, IRR and yearly income.

Projections are illustrative, before tax, and not a promise of returns.
